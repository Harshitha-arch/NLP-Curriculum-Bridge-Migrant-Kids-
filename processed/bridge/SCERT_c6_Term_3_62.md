## What you already know
You may have used a mobile phone or a computer. When you tap a screen or type, something inside the machine has to understand you and show a result.

## Lesson
Today we learn about **system software**.

A computer has **hardware**. Hardware is the physical parts of a computer that you can touch, such as the keyboard, the screen, and the machine itself.

A computer also needs **software**. Software is the set of instructions that tells the hardware what to do.

One special kind of software is called **system software**. Another name for it is the **operating system**. It is the software that makes the hardware devices work together.

Here is what the operating system does:

1. It takes the **data** that the user gives. Data is the information you put into the computer.
2. It makes the hardware **process** the data. To process means to work on the data and change it into a result.
3. It shows the result on the **output** devices. An output device shows or gives out the result. The **monitor** is one example.

The operating system is very important. **Without the operating system, a computer cannot function on its own.** The computer cannot do its work by itself.

Some popular operating systems are Linux, Windows, Mac, and Android. These are names you may hear or see. Each one is a system software.

Remember this:
- Hardware is the parts you can touch.
- Software is the instructions.
- System software, or the operating system, makes the hardware work with the data and show the result.

## Key words
- **System software**: software that makes the hardware devices work and process data.
- **Operating system**: another name for system software.
- **Hardware**: the physical parts of a computer that you can touch.
- **Software**: the instructions that tell the hardware what to do.
- **Data**: the information that the user puts into the computer.
- **Process**: to work on data and change it into a result.
- **Output device**: a device that shows or gives out the result, such as a monitor.
- **Monitor**: the screen that shows the result.
- **Linux**: a name of a popular operating system.
- **Android**: a name of a popular operating system.

## Practice questions
1. What is another name for system software?
2. What does the operating system do with the data that the user gives?
3. Why can a computer not function on its own without an operating system?
4. Name two popular operating systems from the lesson.
5. Your mobile phone shows results on its screen. Which operating system from the lesson might it use?

## Answers
1. Another name for system software is the operating system.
2. The operating system makes the hardware process the data and then shows the result on the output devices.
3. Without the operating system, the computer cannot do its work by itself.
4. Any two of these: Linux, Windows, Mac, Android.
5. Android is one operating system from the lesson that is used on phones.
