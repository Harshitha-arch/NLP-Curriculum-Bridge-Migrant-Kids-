## What you already know
You already use things you can touch, like your school bag, pencil box, or water bottle. You also use things you cannot touch, like a song on a phone or the instructions that tell a washing machine what to do.

## Lesson
A computer has two main parts. One part is **hardware**. The other part is **software**.

**Hardware** is the parts of the computer that we can touch and feel. Hardware includes:
- Input and output devices
- The cabinet (the box that holds the parts)
- The hard disk
- The motherboard
- SMPS
- CPU
- RAM
- CD drive
- Graphics card

**Software** is different. You cannot touch or feel software. Software is made of programmed and coded applications. These applications process the input information. This means the software takes the information you give the computer and works on it. The software changes the input information into coding, which is the programmed language the computer understands.

Hardware cannot work alone. Hardware is lifeless without software. A computer with only hardware cannot do useful work. The software gives the hardware its work to do.

We can see the work of the software in the form of output. Output is the result that the computer shows us.

Software is divided into two types:
1. **System software**, also called the operating system
2. **Application software**

Remember this simple rule: if you can touch it, it is hardware. If you cannot touch it, and it tells the computer what to do, it is software.

## Key words
- **Hardware**: the parts of a computer that you can touch and feel.
- **Software**: the programs and coded applications that tell the computer what to do. You cannot touch them.
- **Input**: information that you give to the computer.
- **Output**: the result the computer shows you.
- **Data**: information that the computer works on.
- **Program**: a set of instructions that tells a computer what to do.
- **Motherboard**: a main board inside the computer that holds many of its parts.
- **Operating system**: the system software that runs the computer.
- **Application software**: software that does a particular job for the user.
- **System software**: software that controls the basic working of the computer.

## Practice questions
1. What is hardware?
2. Name any two parts of hardware given in the lesson.
3. Why is hardware called lifeless without software?
4. What are the two types of software?
5. Your school bag is hardware, but a song on a phone is not hardware. Why is a song not hardware?

## Answers
1. Hardware is the parts of the computer that we can touch and feel.
2. Any two of: input and output devices, cabinet, hard disk, motherboard, SMPS, CPU, RAM, CD drive, graphics card.
3. Hardware cannot do useful work by itself. Software gives the hardware its work to do.
4. The two types of software are system software (operating system) and application software.
5. A song is not hardware because you cannot touch or feel it. It is software, which is made of coded programs.
