## What you already know

You use a calculator to add, subtract, multiply and divide numbers. You also keep things in a notebook or a school bag so you can find them again. A computer also has parts that do similar work.

## Lesson

A computer has a main part that does most of the work. It is called the **CPU** (Central Processing Unit). Think of the CPU as the brain of the computer.

The CPU has three parts:

1. **Memory Unit**
2. **Arithmetic Logic Unit (ALU)**
3. **Control Unit**

Let us learn each part.

**The Control Unit** is the boss of the computer. It controls the work of all the other parts. It tells each part what to do and when to do it.

**The Arithmetic Logic Unit (ALU)** does the maths. It does addition, subtraction, multiplication and division. When you ask the computer to add two numbers, the ALU does the adding.

**The Memory Unit** keeps data and information. Data means any facts or information the computer works with. The memory unit saves this data, but only for a short time. We say it saves data *temporarily*. "Temporarily" means "for a short while, not forever."

The memory unit is of two types. They are called **primary memory** and **secondary memory**.

Sometimes a computer needs more space to save data. Then we can add more memory from outside the computer. This is called expanding memory externally. Things we can use are a **Compact Disk (CD)** and a **Pendrive**.

Computers come in many forms. Three kinds are the **desktop**, the **laptop** and the **tablet**.

So, the CPU is the brain. Inside it, the control unit directs the work, the ALU does the maths, and the memory unit keeps the data for a short time.

## Key words

- **CPU**: the main part of a computer that processes data; it is like the brain of the computer.
- **Data**: facts or information that a computer works with.
- **Memory unit**: the part of the CPU that saves data and information for a short time.
- **Arithmetic Logic Unit (ALU)**: the part that does addition, subtraction, multiplication and division.
- **Control unit**: the part that controls the work of all the other parts of the computer.
- **Temporarily**: for a short time, not forever.
- **Primary memory**: one of the two types of memory unit.
- **Secondary memory**: the other type of memory unit.
- **Compact Disk (CD)**: a disk that can be used to add more memory to a computer from outside.
- **Pendrive**: a small device that can be used to add more memory to a computer from outside.

## Practice questions

1. Name the three parts of the CPU.
2. What does the control unit do?
3. Which part of the CPU does addition and division?
4. Why is the memory unit said to save data *temporarily*?
5. If your computer needs more space, what can you use to add memory from outside? Name one.

## Answers

1. The three parts of the CPU are the memory unit, the arithmetic logic unit (ALU) and the control unit.
2. The control unit controls the functions of all parts of the computer.
3. The arithmetic logic unit (ALU) does addition and division.
4. The memory unit saves data only for a short time, so it is said to save data temporarily.
5. You can use a Compact Disk (CD) or a pendrive to expand memory from outside the computer.
