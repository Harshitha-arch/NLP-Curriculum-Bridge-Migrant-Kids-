## What you already know
Many people use computers in daily life, at work, at school, and in shops and banks. Your family may use a phone or a computer for many jobs that once took a lot of effort.

## Lesson
Today we start to learn about the parts of a computer.

A computer is used in every walk of life. It eases effort and speeds up many processes. Because of this, it is a good time to learn how a computer is built.

The computer has key units. A unit is a part. The lesson names these parts:

- the **input unit**
- the **CPU**
- the **output unit**
- the **memory unit**

The passage says that knowing these units helps us use a computer with ease. It also says we will learn what each unit does. Its work is called its **function**.

We also learn about **input** and **output devices**. A device is a machine or tool. The passage says we will learn how to tell input devices and output devices apart. It also says we will learn how the parts of a computer are connected.

Remember these ideas:
- A computer has key units.
- Each unit has its own work.
- Knowing the units helps us use a computer.

## Key words
- **Computer**: a machine that helps people do work quickly and with less effort.
- **Unit**: a part of something.
- **Input unit**: the part of a computer that takes things in.
- **CPU**: a main unit of the computer.
- **Output unit**: the part of a computer that gives results out.
- **Memory unit**: the part of a computer that stores things.
- **Device**: a machine or tool.
- **Function**: the work that a part does.
- **Process**: a set of steps to do a job.
- **Connection**: a link between two things.

## Practice questions
1. Name the key units the lesson talks about.
2. What is a unit?
3. What does the passage say a computer does for people?
4. Why does the passage say it is good to learn about the units?
5. Give one example of a computer being used in daily life.

## Answers
1. The lesson talks about the input unit, the CPU, the output unit and the memory unit.
2. A unit is a part of something.
3. The passage says a computer eases effort and speeds up processes.
4. The passage says that understanding the units helps us use a computer with ease.
5. Answers will vary. A child may name a bank, a shop, a school or a phone as an example.

## Note for the teacher
This lesson is based only on the short SCERT introduction to "Parts of Computer." The passage names the input unit, CPU, output unit and memory unit, and it says there are three key units, so the teacher should check which three are meant. The passage does not explain what each unit does or give device examples, so these are left out and should be taught from the following SCERT pages.
