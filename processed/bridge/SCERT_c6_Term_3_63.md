## What you already know

You may use a phone or computer to play music, take photos, or type a letter. Each of these jobs is done by a program, which is a set of instructions that tells the computer what to do.

## Lesson

Today we learn about **application software**. Software means programs. A computer needs programs to do its work.

Application software is a program, or a group of programs, made to help the **end user**. The end user is the person who uses the computer. Application software helps this person do a job on the computer.

Application software can be put into the **hard disk** of a computer. The hard disk is the part of the computer that stores programs and files. When a program is put into the hard disk, we say it is **installed**. Once installed, it can be used on that one computer.

One application program can finish one work for the user. It can also finish two or more works. Here are some examples:

- **Video player**: plays videos.
- **Audio player**: plays sound, such as songs.
- **Word processing software**: helps you write and edit text, such as a letter or a story.
- **Drawing tools**: help you draw pictures on the computer.
- **Editing software**: helps you change and improve a file.

Think of a music player on your phone. You open it, choose a song, and listen. That is an application program doing a work for you.

Application software comes in two forms:

1. **Free and open source**: You can get it without paying. "Open source" is a word used for this kind of software.
2. **Paid and proprietary**: You have to pay to get it. "Proprietary" is a word used for software that is owned and controlled by its maker.

So, application software is the set of programs that help us do our everyday work on a computer.

## Key words

- **Application software**: programs that help the user do a job on the computer.
- **Program**: a set of instructions that tells a computer what to do.
- **End user**: the person who uses the computer.
- **Hard disk**: the part of a computer that stores programs and files.
- **Install**: to put a program into the computer so it can be used.
- **Word processing software**: a program for writing and editing text.
- **Drawing tools**: programs for drawing pictures on a computer.
- **Editing software**: a program for changing and improving a file.
- **Free and open source**: software you can get without paying.
- **Paid and proprietary**: software you have to pay for.

## Practice questions

1. What is application software?
2. Name two examples of application software.
3. What does one application program do for the end user?
4. Where is application software installed on a computer?
5. You want to play a song on your home computer. Which type of application software would you use?

## Answers

1. Application software is a program, or a group of programs, designed to help the end user work on a computer.
2. Two examples are video player and audio player (you may also name word processing software, drawing tools, or editing software).
3. It completes one or more works for the end user.
4. It can be installed in the hard disk for use on a particular computer.
5. You would use an audio player.
